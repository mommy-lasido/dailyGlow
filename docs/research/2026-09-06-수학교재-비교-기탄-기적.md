# 수학 교재 비교 — 기탄수학 vs 기적의 계산법

조사일: 2026-09-06 · 목적: DailyGlow 앱의 "수학 단계표"를 어느 실제 교재의 순서에 맞출지 결정.
한글 과목이 『기적의 한글 학습』(길벗스쿨) 35단계를 그대로 옮겨 잘 작동한 것처럼, 수학도 실제 교재의 순서를 따르려는 것.

> 읽는 법: "확인됨"은 출판사 또는 서점 상품페이지에서 직접 본 내용, "소개만 있음"은 홍보 문구는 있으나 실제 목차(차례)는 확인하지 못한 것. 모든 구체적 수치 옆에 출처 링크를 달았다.

---

## 1. 한 줄 요약

**앱의 수학 단계는 『기적의 계산법 예비초등』(40단계) → 『기적의 계산법』(초1~초6, 120단계)의 순서를 따르는 게 낫다.**
이유는 하나뿐이다 — 기적 쪽은 "1단계·2단계·3단계…"로 번호가 매겨진 목차가 출판사 홈페이지에 통째로 공개되어 있어서, 한글 35단계처럼 그대로 옮길 수 있다.
기탄수학은 A~O단계로 크게만 나뉘고, 그 안에서 무엇을 며칠째 배우는지(세부 순서)를 공개된 곳에서 찾을 수 없었다. 어머니가 기탄수학을 집에서 쓰시더라도, 앱 내부의 단계 번호까지 기탄에 맞출 이유는 약하다.

**세 살(도윤)에게는:** 어느 교재도 만 3세용 "계산" 과정이 없다. 기적의 계산법·예비초등은 사실상 6~7세부터, 기탄수학은 4~5세부터다. 만 3세가 걸치는 건 『기탄사고력수학 A단계(3~7세)』뿐인데, 이건 계산이 아니라 분류·비교·패턴·1~5 세기 같은 "수학 준비 활동"이다. → 도윤 홈 화면에서는 덧셈 게임을 빼고, 수 세기 이전의 활동만 노출하는 게 맞다.

## 2. 기탄수학 (기탄교육)

### 2-1. 제품군 — 세 가지가 섞여 있다

| 제품 | 무엇인가 | 대상 |
|---|---|---|
| **기탄수학** | 연산(계산) 전문 학습지. A~O단계. | 4~5세 ~ 예비 고1 |
| **기탄사고력수학** | 연산 + 도형·규칙·자료를 학교 학년 순서에 맞춰 섞은 종합 학습지 (아래 4번 항목) | 유아 ~ 초5·초6 수준 |
| **기탄 유아수학 / 기탄 한글수학 등** | 유아 단독 라인이 별도로 있으나, 이번 조사에서 목차 확인 못 함 | 유아 |

- "기탄수학"과 "기탄사고력수학"은 **다른 제품**이다. 이름이 비슷해 서점에서도 섞여 표기된다.
- 출처: [나무위키 '기탄'](https://namu.wiki/w/%EA%B8%B0%ED%83%84), [위키백과 '기탄수학'](https://ko.wikipedia.org/wiki/%EA%B8%B0%ED%83%84%EC%88%98%ED%95%99), [예스24 기탄 사고력 수학 시리즈](https://m.yes24.com/Category/Display/001001044007005005)

### 2-2. 구성 (기탄수학 = 연산 라인)

- **단계 이름:** 알파벳 한 글자 — A, B, C … N, O. (권/과정/급수 표기가 아니라 "단계".)
- **총 단계 수:** 자료마다 다름.
  - 위키백과: **A~N, 14단계** ([링크](https://ko.wikipedia.org/wiki/%EA%B8%B0%ED%83%84%EC%88%98%ED%95%99))
  - 2024년에 **O단계(고등 공통)가 신설**됨 → 현재는 **A~O, 15단계** ([교보문고 '기탄수학 O단계 세트(전5권)'](https://product.kyobobook.co.kr/detail/S000215159067), [알라딘 기탄수학 O-1](https://www.aladin.co.kr/shop/wproduct.aspx?ItemId=355377480))
- **한 단계 = 5집** (예: A단계는 A1·A2·A3·A4·A5). 전체 약 70권. ([위키백과](https://ko.wikipedia.org/wiki/%EA%B8%B0%ED%83%84%EC%88%98%ED%95%99), [ibookpark 기탄수학 A단계](https://ibookpark.com/product/%EA%B8%B0%ED%83%84%EC%88%98%ED%95%99-a%EB%8B%A8%EA%B3%84/))
- **한 집 = 60장**, 소화 기간 약 1개월. ([위키백과](https://ko.wikipedia.org/wiki/%EA%B8%B0%ED%83%84%EC%88%98%ED%95%99))
- C단계~N단계는 1~4집에 성취도 테스트, 5집에 종료 테스트. ([위키백과](https://ko.wikipedia.org/wiki/%EA%B8%B0%ED%83%84%EC%88%98%ED%95%99))

### 2-4. 학습 순서 (얼마나 구체적으로 알 수 있나)

**큰 흐름은 확인됨:**
숫자 인식·수 세기·기초 쓰기(A~B) → 덧셈·뺄셈(C~E) → 곱셈·나눗셈(F~G) → 복합 연산·분수·소수(H~J) → 유리수·방정식·함수(K~M) → 고등 연산(N~O).
- "B단계부터 시작되는 덧셈 학습에 필요한 수의 성질과 순서성을 이해하는 것이 A단계의 목표"라는 서술은 확인됨 ([검색 인용, 원문 미확인 블로그·서점 요약])
- 출처: [위키백과 '기탄수학'](https://ko.wikipedia.org/wiki/%EA%B8%B0%ED%83%84%EC%88%98%ED%95%99)

**세부 순서는 확인 못 함 (중요):**
A-1이 무엇, A-2가 무엇, "수 세기 → 숫자 쓰기 → 모으기·가르기 → 덧셈"이 몇 집 몇째 날에 나오는지 — 이걸 담은 **공식 목차(차례)를 교보·예스24·알라딘·기탄교육 홈페이지 어디에서도 찾지 못했다.** 서점 페이지는 "4~5세용, 개인별·능력별 프로그램" 수준의 홍보 문구와 샘플 이미지 몇 장만 준다.
→ 이 부분은 **책을 펼쳐 찍어야** 알 수 있다 (7-2 참고).

### 2-5. 소량 반복 / 하루 분량

- **맞다.** "하루 5~10분", 한 집 60장을 약 1개월에 소화 → **하루 약 2장**. 소량을 매일 반복하는 방식. ([위키백과](https://ko.wikipedia.org/wiki/%EA%B8%B0%ED%83%84%EC%88%98%ED%95%99))
- 단, 이 서술의 1차 출처는 위키백과다. 기탄교육 공식 페이지의 동일 문구는 확인하지 못했다.

### 2-6. 세 살에게 충분히 이르게 시작하나?

- 아니다. **A단계 = 4~5세**가 최저. 만 3세(도윤)는 대상 아님.
- 기탄사고력수학 A단계는 서점 표기상 "3~7세"라 만 3세가 걸치긴 하나, 그건 계산이 아니다(4번 항목).

## 6. 못 찾은 것 / 불확실한 것 (솔직하게)

1. **기탄수학의 집별 세부 목차** — A-1~D-5가 각각 무엇을 다루는지, "수 세기→숫자 쓰기→모으기·가르기→덧셈"이 몇 단계 며칠째인지. 교보·예스24·알라딘·기탄교육 홈페이지 어디에도 차례(목차)가 없다. **이건 책을 펼쳐 찍어야만 알 수 있다.**
2. **기탄수학 총 단계 수** — 위키백과는 A~N(14단계), 2024년 O단계 신설로 지금은 A~O(15단계). 유아~초등 구간(A~J)은 변동 없음.
3. **기탄의 "하루 5~10분·소량 반복" 서술의 1차 출처** — 위키백과·나무위키에는 있으나 기탄교육 공식 페이지에서 같은 문구를 확인하지 못함. 방향성은 맞다고 봄.
4. **기탄사고력수학의 단계별 대상 연령** — 서점마다 표기가 어긋난다(특히 E단계). 초3 = G단계는 두 곳이 일치.
5. **기탄사고력수학 하루 분량** — 상품 페이지에 명시 없음.
6. **기적의 계산법 초등 5~10권(초3~초5)의 단계별 제목** — 형식은 확실(권당 10단계)하나 제목을 하나하나 확인하지는 않았다. 1·3·12권은 확인.
7. **기적의 계산법 예비초등 5권(33~40단계) 목차** — 검색 요약으로는 확인, 출판사 원 페이지에서 재확인 권장.
8. **기탄 유아 단독 라인**(기탄사고력수학과 별개) — 존재는 하나 목차 미확인.

## 7. 추천

### 7-1. 앱의 수학 단계를 어떻게 짤까

**『기적의 계산법 예비초등』 40단계 + 『기적의 계산법』 초등 120단계 = 총 160단계를 하나의 번호열로 삼는다.** 한글 35단계표(`packages/utils/src/hangul-stages.ts`)와 똑같은 방식.

- **1~40단계:** 예비초등 (10까지의 수 → 몇십몇의 덧셈·뺄셈). 4번 목차표를 그대로 옮기면 된다 — 이미 이 문서에 전부 있다.
- **41~160단계:** 초등 계산법 1~12권, 권당 10단계. 초1(41~60) → 초6(151~160). 각 단계 제목은 출판사 페이지에서 마저 옮겨야 한다.
- **과목 레벨 매핑:** 한글처럼 `profile_subject_levels.level` = 이 단계 번호.
- **도윤(만 3세):** 이 표의 1단계에도 못 미친다. 수학 과목 레벨을 "0"(또는 미설정)로 두고, 홈 화면에서는 **덧셈·계산 활동을 노출하지 않는다.** 대신 수 세기 이전 활동(양 비교, 같은 것 찾기, 분류 — 기탄사고력수학 A단계가 다루는 종류)을 별도 콘텐츠로. 이건 워크북 게이팅 대상이 아니라 자유 노출로.
- **시윤(유치원):** 예비초등 1~16단계 근처에서 부모가 실제 위치를 지정.
- **라윤(초3):** 계산법으로는 5~6권(초3) 구간. 별도로 원하시는 **사고력 수학**은 기탄사고력수학 G단계가 후보이나, 연산이 섞여 있어 "계산 드릴 배제" 요구와는 어긋난다. 순수 도형·규칙·논리를 원하면 팩토·시매쓰 등 별도 검토가 필요(이번 조사 범위 밖).

**기탄수학을 집에서 쓰시는데도 기적을 앱 기준으로 삼는 이유:** 앱은 번호가 매겨진 공개 단계표가 있어야 하는데, 그건 기적만 제공한다. 어머니는 집에서 기탄수학 교재로 계속 가르치시면 되고, 앱 단계 번호가 교재 브랜드와 꼭 같을 필요는 없다. 아이의 실제 실력 위치만 부모가 지정하면 된다.

### 7-2. 어머니가 무엇을 찍어 보내주시면 확정되나

**앱을 기적의 계산법 순서로 갈 경우 — 촬영 거의 불필요:**
- 40단계 목차는 이 문서에 이미 있음.
- 초등 계산법 5~10권(초3~초5) 단계 제목만 출판사 페이지에서 마저 옮기면 됨(내가 마무리 가능).
- 정확성 검증용으로 원하시면: 서점/도서관에서 **『기적의 계산법 예비초등』 세트의 각 권 첫머리 "목차" 페이지 5장**, **『기적의 계산법』 1~12권 각 권 "목차" 페이지**를 찍어주시면 100% 확정.

**만약 앱을 어머니가 쓰시는 기탄수학 순서에 맞추고 싶다면 — 촬영 필수:**
- 소유하신 기탄수학 각 집(예: A-1 ~ D-5)의 **맨 앞 "학습 계획표 / 목차 / 이번 집에서 배우는 내용" 페이지**.
- 각 단계 표지 뒤의 **급수표(A~O 단계 안내표)** — 어느 단계가 무엇을 배우는지 한 장 요약.
- 이게 있어야 기탄의 세부 순서를 앱에 옮길 수 있다. (지금은 인터넷에 공개돼 있지 않음.)

**초3 사고력 수학을 기탄사고력수학으로 검토하려면:**
- **『기탄사고력수학 G단계』 G1~G6 각 권의 목차 페이지 6장.** 이걸 보고 연산을 뺀 도형·규칙·논리 문항만 골라 화면 놀이로 옮길 수 있을지 판단.
