작성일: 2026-09-05

대화로 나온 아이디어를 적어둔다. 정해진 계획이 아니라 후보 목록이며, 만들 때가 되면
해당 Phase 계획서로 옮긴다.

---

## 지금 있는 문제 — 수학에 단계가 없다

한글은 35단계로 촘촘히 나뉘어 있어 도윤이(1단계)에게 문장 읽기가 안 나온다. **수학은
단계가 사실상 없다.** `더하기 놀이`와 `100칸 계산`이 둘 다 `subject_level 1`이라, 지금
**도윤이(만 3세) 홈에 "더하기 놀이"가 떠 있다.** 수를 셀 줄도 모르는 아이에게 3+2가 나온다.

수학 단계 체계를 만드는 것이 가장 급하다.

---

## 1. 수학 — 단계 체계

유아부터 초등까지의 자연스러운 순서 초안. 확정 아님 — 실제 교재나 교육과정으로 검증이 필요하다.

| 단계 | 내용 | 비고 |
|---|---|---|
| 1 | 수 세기 1~5 | 도윤이 여기서 시작 |
| 2 | 수 세기 1~10 | |
| 3 | 수 세기 1~20 | |
| 4 | 숫자 알아보기 (모양과 이름) | |
| 5 | 많다·적다 견주기 | |
| 6 | 모으기와 가르기 | 한국 교육과정의 핵심 |
| 7 | 한 자리 덧셈 (합 10 이하) | **지금 만든 더하기 놀이가 여기** |
| 8 | 한 자리 뺄셈 | |
| 9 | 10 만들기 · 10 가르기 | |
| 10 | 받아올림 있는 덧셈 | |
| 11 | 받아내림 있는 뺄셈 | |
| 12 | 두 자리 셈 | |
| 13 | 묶어 세기 → 구구단 | |
| 14 | 나눗셈 | |

`100칸 계산`은 이 위에 얹히는 **속도 훈련**이다 — 어떤 연산이든 익숙해진 뒤 빨라지게 하는 용도.

**검증할 것:** 같은 출판사(길벗스쿨)의 「기적의 계산법」 구성, 2022 개정 수학과 교육과정
초1~2 "수와 연산" 성취기준, 누리과정의 유아 수 개념. 한글 때처럼 실제 교재 순서를 따르는
편이 낫다.

## 2. 사고력 수학 (라윤)

계산이 아니라 **오래 생각하는** 활동. 화면에 잘 맞는 것과 종이가 나은 것이 갈린다.

| 놀이 | 화면에 맞나 | 문제를 누가 만드나 |
|---|---|---|
| **규칙 찾기** (🔴🔵🔴🔵 다음은? / 2,4,8,16…) | 아주 잘 맞음 | **프로그램이 무한히** |
| **마방진 · 벌집셈** (빈칸에 들어갈 수) | 잘 맞음 | **프로그램이 무한히** |
| **쌓기나무 세기** (그림 보고 개수) | 잘 맞음 | 프로그램이 만들 수 있음 |
| **도형 돌리기·뒤집기** (보기 4개 중 고르기) | 잘 맞음 | 프로그램이 만들 수 있음 |
| 경우의 수 | 됨 | 손으로 |
| 논리 추론 (조건으로 맞추기) | 글이 길어짐 | 손으로 |
| 도형 넓이 · 전개도 · 종이접기 | **종이가 나음** | — |

**중요 — 흐름이 달라야 한다.** 사고력은 "빨리 많이"가 아니다.

| | 계산 놀이 | 사고력 놀이 |
|---|---|---|
| 문제 수 | 10개 | **3~5개** |
| 속도 | 빠르게 | 천천히, 시간 제한 없이 |
| 힌트 | 3차에만 | **더 일찍, 더 친절하게** |

spec §14 의 3단계 흐름을 그대로 쓰되 문제 수만 줄이고 힌트를 풍부하게 하면 맞는다.

**새로운 점:** 그림이 필요하다. 지금까지 활동은 글자와 숫자뿐이었다. 쌓기나무·도형은
SVG 로 그려야 한다 — 어렵진 않지만 안 해본 일이다.

## 3. 국어 고학년 (라윤, 초3~)

한글 → 맞춤법으로 저학년까지는 이어지는데, 그 뒤가 비어 있다.

| 놀이 | 화면에 맞나 | 근거 자료 |
|---|---|---|
| **어휘력** (뜻 고르기, 비슷한 말·반대말) | 아주 잘 맞음 | 국립국어원 어휘 등급 **3~5등급** |
| **속담 · 관용어** | 잘 맞음 | 조사 필요 |
| **띄어쓰기** | 맞음 — 맞춤법 구조 재사용 | 한글 맞춤법 규정 원문 |
| 독해 (짧은 글, 중심 생각) | 글이 길어 **종이가 나음** | — |

**추천은 어휘력 + 속담·관용어.** 초등 고학년 교과서가 어려워지는 진짜 이유가 한자어
어휘다 — "관찰", "비교", "특징" 을 모르면 수학·사회·과학이 다 막힌다. 마침 국립국어원
어휘 목록이 나이별 등급으로 나뉘어 있어 근거가 확보된다
(`docs/research/2026-09-05-초등-기초어휘-맞춤법-공공자료.md`).

## 4. 아직 비어 있는 것

- **영어** — 과목은 만들어져 있으나 활동이 하나도 없다.
- **생활 수학** — 시계 보기, 돈 세기, 달력. 유아~초저 사이에 자연스럽게 들어간다.

## 만들 수 있는 시점

| 이런 놀이라면 | 언제 |
|---|---|
| 정답이 있는 객관식 | **지금 바로** — spec §14 의 3단계 흐름을 그대로 씀 |
| 그림·소리만 쓰는 놀이 | 지금 바로 |
| 한글 글자·낱말·문장이 나오는 것 | Phase 2b 이후 (자모 시스템 필요) |
| 종이에 인쇄해서 하는 것 | Phase 3 이후 |
| 사진 찍어 채점하는 것 | Phase 4 이후 |

Phase 2a 가 끝나면 새 활동 하나는 **컴포넌트 하나 + 레지스트리 한 줄**로 붙는다.
로그인·기록·아이별 단계 맞춤은 이미 돌아가고 있다.
