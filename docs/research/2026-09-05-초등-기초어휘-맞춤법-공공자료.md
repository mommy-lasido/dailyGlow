# 맞춤법·낱말 자료 조사 — 국립국어원/교육부에 쓸 만한 공식 자료가 있는가

조사일: 2026-09-05
조사 방법: 국립국어원(korean.go.kr), 공공데이터포털(data.go.kr), 교육부(moe.go.kr), 국가기초학력지원포털(basics.go.kr) 등 공식 웹사이트를 직접 검색·열람. 블로그·나무위키 등은 참고만 하고 인용하지 않음.

---

## 1. 한 줄 요약

**낱말(어휘) 쪽은 국립국어원에 상업적 이용까지 가능한 공식 목록이 실제로 존재한다. 맞춤법(헷갈리는 표기 쌍) 쪽은 "규정 원문"은 공식으로 받을 수 있지만, "안/않처럼 짝을 지어 설명한 목록"은 국립국어원도 교육부도 공식 배포판을 만들어 놓지 않았다 — 그건 결국 누군가 손으로 골라야 하는 영역이다.**

| 필요한 것 | 공식 자료 있음? | 상업적 이용 가능? |
|---|---|---|
| 낱말 읽기용 기초 어휘 목록 | 있음 (국립국어원, 최신) | 가능 (공공누리 제1유형) |
| 맞춤법 규정 원문 | 있음 | 출처표시만 하면 가능 |
| "헷갈리는 맞춤법 짝" 목록 자체 | 없음 (공식 편집본 없음) | 해당 없음 |
| 초1~2 자모 도입 순서 공식 문서 | 못 찾음 | — |
| 한글 해득 진단 도구 | 있음(교육 현장용), 가정용 다운로드는 불확실 | — |

## 2. 찾은 것

### 2-1. 국립국어원 — 어휘 목록 (낱말 읽기에 바로 쓸 수 있는 것)

| 자료명 | 어디서 | 내용 | 규모 | 이용조건 |
|---|---|---|---|---|
| **국어 기초 어휘 선정 및 어휘 등급화 목록 (2023년 연구, 2024.5.31 발표)** | [korean.go.kr 보고서 자료실](https://www.korean.go.kr/front/reportData/reportDataView.do?mn_id=45&report_seq=1160) — 첨부파일 "국어 기초 어휘 선정 및 어휘 등급화 목록 전체.xlsx" | 국민이 실제 습득하는 시기 기준 **5개 등급**으로 나눈 어휘 목록. 1등급(4~6세, 학령전) 5,000개, 2등급(7~8세, 초1~2 수준) 2,500개. 3~5등급도 있으나 기사에는 정확한 개수가 안 나옴(보고서 원문 확인 필요). | 총 약 4만 개 | **공공누리 제1유형** — 출처표시만 하면 상업적 이용·2차 저작물 작성(변형) 모두 가능. (보고서 PDF 자체는 제4유형이라 원문은 손대면 안 되지만, 어휘 목록 엑셀 파일은 제1유형으로 별도 표시돼 있음) |
| **한국어 학습용 어휘 목록 (2003년, 외국인 학습자용)** | [korean.go.kr 자료실](https://www.korean.go.kr/front/etcData/etcDataView.do?mn_id=46&etc_seq=71) | 초급 982개·중급 2,111개·고급 2,872개, 가나다순, 사용빈도 순위 포함. 엑셀·텍스트·한글(hwp) 3가지 형식 | 5,965개 | 공공누리 제1유형 |

**중요 참고:** 2003년 자료는 "외국인을 위한 한국어" 기준이라 성인 학습자용 단어(공항, 대사관, 여권 등)가 섞여 있어 유치원생·미취학 아동에게는 안 맞는다. 반면 **2024년에 새로 나온 "국어 기초 어휘"는 나이·학령 기준으로 등급을 나눴기 때문에 시윤·도윤 나이대(4~8세)에 맞는 단어만 추려 쓰기에 훨씬 적합하다.** 이게 이번 조사에서 가장 쓸 만한 발견이다. 다만 실제로 어떤 글자가 들어있는지는 엑셀 파일을 직접 열어봐야 확인된다 — 이번 조사에서는 파일 존재와 조건만 확인했고, 파일 내용(구체적으로 어떤 단어들인지)까지는 열어보지 못했다.

### 2-2. 국립국어원 — 사전 오픈 API

| 자료명 | 어디서 | 내용 | 이용조건 |
|---|---|---|---|
| **우리말샘 오픈API** | [공공데이터포털](https://www.data.go.kr/data/15105193/openapi.do) / [krdict.korean.go.kr](https://krdict.korean.go.kr) | 단어 뜻·발음·용례·품사 등. JSON+XML 형식, 무료, 인증키 필요 | 페이지에 "이용허락범위 제한 없음"이라 표시 — 상업적 이용 가능한 것으로 보임. 단, 정확한 공공누리 번호(1~4유형)까지는 이 페이지에서 명시적으로 확인하지 못함. |
| **표준국어대사전 오픈API** | [stdict.korean.go.kr/openapi](https://stdict.korean.go.kr/openapi/openApiInfo.do) | 표제어 검색, 뜻풀이 | 인증키 필요, 무료. **저작권 정책 페이지가 별도로 있는데 이번 조사에서는 그 하위 페이지의 정확한 라이선스 유형을 확인하지 못했다** — "공공누리 제1유형"이라는 언급을 다른 검색 결과에서 봤지만, stdict 사이트 자체 페이지에서 직접 재확인은 못 했음. 실제 사용 전에 저작권 정책 페이지를 다시 확인 필요. |

이 두 API는 "이 단어가 맞는 표준어인지, 뜻이 뭔지"를 실시간으로 조회하는 용도지, 맞춤법 짝 목록이나 초등 어휘 목록 그 자체를 제공하지는 않는다. 앱에서 사전 찾기 기능을 넣고 싶을 때 유용한 자료다.

## 3. 못 찾은 것 / 불확실한 것 (솔직하게)

- **"안/않, 되/돼처럼 짝지어진 헷갈리는 맞춤법 공식 목록"은 국립국어원에도 교육부에도 없어 보인다.** 국립국어원 온라인가나다(질의응답 게시판)에 개별 사례들이 쌓여 있고, 계간지 「쉬운 우리말을 쓰자」 같은 간행물도 있지만, 이것들은 "정리된 100개 리스트" 형태가 아니라 흩어진 Q&A와 기사 모음이다. 즉 지금 앱에 있는 95개 손수 정리본과 비슷한 수준의 결과물을 국가기관이 이미 만들어 놓은 건 못 찾았다.
- **표준국어대사전 오픈API의 정확한 공공누리 유형**은 사이트에서 명시적으로 재확인하지 못했다. 실제 사용 전 저작권 정책 페이지를 다시 봐야 한다.
- **우리말샘 API의 정확한 공공누리 번호(1~4유형 중 몇 번인지)**도 페이지에 "제한 없음"이라고만 나오고 숫자로 명시된 걸 확인하지 못했다.
- **2022 개정 국어과 교육과정 별책5 부록에 실제 단어 목록이 있는지**는 문서 제목만 확인했고 본문 페이지까지 열어보지 못했다.
- **초1~2 교과서의 정확한 자모 도입 순서(어떤 자음/모음을 몇 주 차에 배우는지)를 공식 문서로 공개해 놓은 자료**는 찾지 못했다. 이 순서를 알려면 실제 교과서(예: 미래엔, 천재교육 등 검정교과서)나 지도서를 직접 봐야 할 가능성이 높다.
- **한글 또박또박·찬찬한글 자료를 가정에서 그대로 내려받아 쓸 수 있는지**, 그리고 2026년 2월 포털 통합 이후 자료 위치가 어디로 옮겨갔는지는 확인하지 못했다. 이 조사 시점(2026-09)에 다시 basics.go.kr에 접속해서 확인해야 한다.
- 국어 기초 어휘 엑셀 파일(4만 개)의 **실제 내용물**(어떤 단어가 몇 등급에 들어있는지)은 파일을 열어보지 못해 확인 못 함. 존재와 라이선스만 확인.

**주의:** 위에서 "확인 못 함"이라고 쓴 항목은 정말로 확인하지 못한 것이며, 링크나 수치를 지어내지 않았다. 실제로 자료를 쓰기 전에는 반드시 원문 페이지를 열어 다시 확인하는 걸 권한다.

## 4. 추천

### 맞춤법 탐험대 (라윤, 95개 짝)

**지금 있는 손으로 만든 95개를 계속 쓰는 걸 추천한다.** 국가기관이 "짝지어 설명한 맞춤법 목록"을 공식적으로 배포하지 않기 때문에, 이 부분은 애초에 대체할 공식 자료가 없다. 다만:

- 각 짝의 **설명 문구(왜 틀렸는지)** 는 한글 맞춤법 규정 원문(공공누리 제1유형, 출처표시하면 상업적 이용도 가능)을 근거로 다시 검토해서 조문 번호를 인용해두면, 나중에 앱이 공개됐을 때 "이거 어디서 나온 규칙이에요?"라는 질문에 답하기 쉬워진다.
- 표준국어대사전/우리말샘 API를 연결해두면, 아이가 헷갈리는 단어를 검색했을 때 정식 사전 뜻풀이를 보여줄 수 있다 (다만 API 라이선스 조건 재확인 필요).
- 95개 목록 자체를 국가기관 자료로 "교체"할 필요는 없다 — 애초에 그런 자료가 없으므로 지금 방식이 최선이다.

### 낱말 읽기 / 문장 읽기 (시윤·도윤)

**"섞어 쓰기"를 추천한다.** 구체적으로:

1. **단어 선택(어떤 낱말을 등장시킬지)** 은 국립국어원의 2024년 "국어 기초 어휘" 1~2등급(4~8세, 총 7,500개, 공공누리 제1유형이라 상업적 이용·재가공 가능)에서 뽑아 쓰는 게 손으로 고르는 것보다 더 근거 있고, 나중에 앱이 공개돼도 출처를 떳떳하게 밝힐 수 있다.
2. **자모 학습 순서(어떤 순서로 단어를 내놓을지)** 는 공식 자료를 못 찾았으므로, 기적의 한글 학습의 35단계 순서를 그대로 쓰는 게 현실적이다. 다만 이 부분은 저작권이 있는 시중 교재의 커리큘럼 구조를 참고하는 것이므로 — 이번 조사 범위 밖이지만 — 나중에 앱을 공개한다면 "기적의 한글 학습 순서를 참고했다"는 점을 밝히거나, 순서 자체를 독자적으로 재구성하는 걸 고려할 만하다.
3. 즉, **국립국어원 어휘 목록(무엇을) + 기적의 한글 학습 순서(어떤 차례로)** 를 조합하는 방식을 권한다.

### 다음에 확인하면 좋을 것 (우선순위 순)
