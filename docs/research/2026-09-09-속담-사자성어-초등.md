# 속담·사자성어 활동 콘텐츠 — 라윤(초3)용

조사일: 2026-09-09
목적: 라윤(초등 3학년)에게 줄 "속담·사자성어 3판 퀴즈" 활동에 넣을 문항 재료를 만든다.
조사 방법: 국립국어원(korean.go.kr), 공공데이터포털(data.go.kr), 한국어기초사전(krdict.korean.go.kr),
표준국어대사전 관련 페이지를 직접 열람. 교육과정 관련은 검색으로 문서 존재 여부만 확인.
블로그·위키는 참고만 하고 인용하지 않음.

---

## 1. 한 줄 요약

**"속담·사자성어를 학년별로 정리해 놓은 공식 목록"은 없다.** 국립국어원에는 속담을 조회할 수 있는
사전과 공개 자료가 있지만, 그건 "이 속담의 뜻이 뭔지"를 찾는 용도이지 "초등 3학년이 배우는 속담 40개"
같은 완성된 목록이 아니다. 초등 국어 교과서는 2022 개정 이후 **검정 교과서**(출판사마다 다름)라서
"교과서에 실린 속담 목록"이라는 하나의 공식 답도 없다.

그래서 이 문서의 표(속담 40개·사자성어 30개)는 **거의 전부 제가 초등 눈높이로 직접 고른 것**입니다.
속담·사자성어 자체는 다 실제로 쓰이는 표준 표현이지만, "초3에게 맞다"는 판단과 "쉬운 뜻·예문" 문장은
제가 쓴 것이고, 특정 교과서 수록 여부는 확인하지 못했습니다. 아래에서 어느 항목이 그나마 근거가 있는지
따로 표시했습니다.

| 필요한 것 | 공식 자료 있음? | 상태 |
|---|---|---|
| 속담의 표준 뜻풀이(조회용) | 있음 — 표준국어대사전·한국어기초사전 | 웹에서 한 건씩 검색 가능. 목록 통짜 배포는 확인 못 함 |
| 사자성어(한자성어) 표준 뜻풀이(조회용) | 있음 — 표준국어대사전 | 위와 같음 |
| "초등 O학년용 속담·사자성어 목록" 공식본 | 없음 | 교과서가 검정이라 하나의 공식 목록이 없음 |
| 속담/사자성어 전용 공공 오픈API·데이터셋 | 못 찾음 | data.go.kr에서 전용 데이터셋 발견 못 함 (사전 API만 있음) |
| 교육과정 문서(국어과) | 있음(문서 존재) | PDF 존재는 확인. 학년별 속담 목록은 원래 거기 없음 |

## 2. 조사해서 실제로 찾은 것 (출처와 함께)

### 2-1. 표준국어대사전 — 속담·한자성어 뜻풀이 조회

- 웹사전: <https://stdict.korean.go.kr/>
- 오픈API 안내(공공데이터포털): <https://www.data.go.kr/data/3057780/openapi.do>
  - 제공기관: 문화체육관광부 국립국어원
  - 형식: JSON + XML, 무료(인증키 필요)
  - 이용조건: 위 공공데이터포털 페이지에 **"공공저작물 라이선스 – 출처표시 필수(제1유형)"**로 표시됨.
    공공누리 제1유형은 출처만 밝히면 상업적 이용과 변형(2차 저작물)이 모두 허용되는 유형입니다.

표준국어대사전에는 속담과 한자성어가 각각 하나의 표제어로 등재되어 있고 뜻풀이가 붙어 있습니다.
다만 이번 조사에서 **API를 실제로 호출해 "속담만 뽑아 오기"가 되는지까지는 시험하지 못했습니다.**
그러니 "속담 목록을 API로 그대로 받아올 수 있다"고 단정하지는 않겠습니다. 확인이 필요한 항목입니다.

### 2-2. 한국어기초사전(krdict) — 속담·관용구 탭

- <https://krdict.korean.go.kr/>
- 도움말 페이지 확인 결과: 검색 결과 화면에 **'속담·관용구' 탭**이 있어 특정 낱말이 속담·관용구에서
  어떻게 쓰이는지 조회할 수 있습니다.
- 저작권: 도움말에 "자유 저작권 정책에 기반한 지식 기부로 수록 정보를 자유롭게 활용할 수 있다"는
  취지의 문구가 있으나, **정확한 공공누리 유형 번호는 이 페이지에서 확인하지 못했습니다.**

### 2-3. 국립국어원 자료실 — "표준국어대사전 개정 지침"

- <https://www.korean.go.kr/front/etcData/etcDataView.do?etc_seq=126>
- 이용조건: **공공누리 제1유형(출처표시)**, 추가로 "AI유형(인공지능 학습용)"도 표시됨.
- 다만 이 파일은 사전 편집자용 지침 문서이지 **속담 목록이 아닙니다.** 참고로만 적어 둡니다.

### 2-4. 국립국어원 어휘 자료 (속담·관용표현 포함 언급)

- 검색 중 국립국어원이 접사·의성어·외래어·준말·**관용표현·속담**·문화어 등으로 나눈 어휘 자료를
  제공한다는 언급을 봤습니다. 관련 자료실 예: <https://www.korean.go.kr/front/etcData/etcDataView.do?mn_id=46&etc_seq=71>
- 그러나 이건 주로 **외국인 한국어 학습용(2003년) 어휘 목록**이고, 이번 조사에서
  "속담 부분만 담긴 내려받기 파일"을 직접 열어 확인하지는 못했습니다. 초등 국어용으로 바로 쓸 수
  있는지도 불확실합니다. **확인 필요 항목.**

### 2-5. 공공데이터포털 — 속담/사자성어 전용 데이터셋

- data.go.kr에서 "속담", "사자성어", "고사성어"로 찾아봤지만 **전용 공개 데이터셋이나 오픈API를
  확인하지 못했습니다.** 관련해서 나오는 건 위 2-1의 표준국어대사전 사전 API뿐입니다.
- 즉, "속담 500개가 뜻과 함께 든 CSV를 공공기관이 배포한다" 같은 건 이번 조사로는 찾지 못했습니다.

### 2-6. 교육과정 / 교과서

- 2015 개정 및 2022 개정 국어과 교육과정 문서(PDF)는 국가교육과정정보센터·교육부·교과서 출판사
  사이트 등에 게시되어 있는 것으로 확인됩니다. (예: 2015 개정 국어과 교육과정 별책5 PDF가
  출판사 CDN 등에 올라와 있음)
- 하지만 **교육과정 문서는 원래 "이 학년에 이 속담을 가르쳐라"라고 개별 속담을 나열하지 않습니다.**
  "관용 표현의 뜻을 짐작하며 읽는다"처럼 능력 기준만 적혀 있습니다.
  (성취기준 코드는 제가 정확히 확인하지 못했으므로 여기에 적지 않겠습니다. 추측해서 쓰면 틀린
  번호가 들어갈 수 있어서입니다.)
- 초등 국어는 2022 개정부터 **검정 교과서**(3~4학년은 2024년부터 시행)라 출판사마다 지문·삽화가
  다릅니다. 그래서 **"3학년 교과서에 실린 속담 목록"이라는 단일 공식 목록은 존재하지 않습니다.**
- 검색 중 한 초등교사 블로그가 초등에서 다루는 관용 표현 예시로 아래 3개를 들었습니다
  (블로그라 인용은 참고 수준):
  "발 없는 말이 천 리 간다", "아 해 다르고 어 해 다르다", "가는 말이 고와야 오는 말이 곱다".

  있어(예: 塞 = 변방 새 / 막힐 색), 활동에서는 그 성어에 쓰인 뜻만 보여 주는 게 좋습니다.
- **"교과서에 나온다"는 문구는 앱에 넣지 마세요.** 확인이 안 된 내용입니다. "자주 쓰는 속담"
  정도로만 표현하면 안전합니다.

## 6. 활동 설계 추천

### 6-1. 속담과 사자성어, 묶을까 나눌까 → **나누는 것을 추천**

이유(라윤의 하루에서 무엇이 달라지는지 기준):

- **문제의 생김새가 다릅니다.** 사자성어는 한자 네 글자의 뜻까지 같이 봐야 해서, 속담 문제보다
  화면에 글자가 많고 읽을 게 많습니다. 둘을 섞으면 한 세트 안에서 난이도가 들쭉날쭉해집니다.
- **끝냈다는 느낌을 주기 좋습니다.** "오늘은 속담 10개"처럼 목표가 뚜렷하면 3학년이 끝까지
  갑니다. 40 + 30을 한 통에 넣으면 "언제 끝나지" 싶어집니다.
- 앱 화면(버튼 모양, 3판 흐름)은 똑같이 쓰고, **문제 묶음(속담 묶음 / 사자성어 묶음)만 따로**
  두면 됩니다. 나중에 라윤이 익숙해지면 "속담 5 + 사자성어 5 섞기" 세트를 추가할 수 있습니다.

### 6-2. 3학년에게 10문제가 적당한가, 보기 3개가 적당한가

- **10문제: 적당합니다.** 다만 3판 구조라서, 라윤이 많이 틀리면 실제로 마주하는 문항 수는
  10(1판) + 틀린 것 다시 + 3판(맞을 때까지) 이라 체감 20~30문항이 됩니다. 그래서 10개보다
  많이 잡지 않는 게 좋습니다. 처음 며칠은 **1단계 20개에서 10개만** 뽑아 쓰는 걸 권합니다.
- **보기 3개: 적당합니다.** 4개면 3학년이 읽어야 할 문장이 늘어 지칩니다. 아주 처음(맨 첫 세션)
  에는 **보기 2개**로 시작해 감을 잡게 한 뒤 3개로 올리는 것도 좋습니다.
- 정답 위치는 매번 무작위로 섞어 주세요(늘 가운데가 정답이면 금방 눈치챕니다).

### 6-3. 그럴듯한 오답(틀린 보기) 만드는 법 — 구체적으로

아무 뜻이나 넣으면 "말 조심 얘기"와 "우주 얘기"가 나란히 있어서 너무 쉬워집니다.
아래 규칙으로 만들면 3학년이 "읽고 한 번 생각해야" 풀 수 있습니다.

1. **오답도 진짜 표현의 뜻으로 채운다.** 지어낸 문장 말고, 목록에 있는 다른 속담·사자성어의
   실제 뜻을 가져다 씁니다. 그러면 셋 다 "그럴싸한 교훈"이라 헷갈립니다.
2. **오답 2개의 역할을 나눈다.**
   - 오답 A = **반대 방향**의 뜻. 예: 정답이 "백지장도 맞들면 낫다(같이 하면 낫다)"면,
     오답 A는 "무슨 일이든 혼자 하는 게 마음 편하다".
   - 오답 B = **비슷해 보이지만 결이 다른** 뜻. 예: 오답 B = "작은 것도 모으면 큰 것이 된다"
     (이건 '티끌 모아 태산' 쪽). 협동과 노력이 헷갈리게 됩니다.
3. **소재(등장하는 동물·사물)를 겹치게 한다.** '우물 안 개구리' 문제의 오답에 '우물을 파도
   한 우물을 파라'의 뜻을 넣습니다. 둘 다 '우물'이라 단어만 보고는 못 거릅니다.
   사자성어도 같은 글자가 든 것끼리 묶습니다. 예: '십중팔구' 오답에 '구사일생(겨우 살아남)'과
   '백발백중(다 맞힘)'의 뜻 — 셋 다 숫자가 들어간 성어라 자동으로 안 걸러집니다.
4. **'교훈 태그'로 오답을 자동으로 뽑는다.** 위 속담 표에 태그(협동/노력/말조심/겸손/욕심/
   준비/인과/실수/처지/습관 등)를 붙여 뒀습니다. 오답은 **다른 태그에서 1개 + 같은 태그에서
   1개**를 뽑게 규칙을 정하면, 매번 "너무 뻔한 오답 + 적당히 헷갈리는 오답" 조합이 나옵니다.
5. **뜻→표현 방향 문제의 오답**은, 글자 수·구조가 정답과 비슷한 표현으로 고릅니다.
   예: 정답이 "누워서 떡 먹기"면 오답도 "~기/~다"로 끝나는 짧은 속담("식은 죽 먹기"류가 아니라
   목록 안의 "수박 겉 핥기", "언 발에 오줌 누기" 같은 것)으로 맞춰 길이로 티가 안 나게 합니다.
6. **3판째 힌트**는 표의 '예문'을 쓰되, 표현 자체는 `○○○`로 가려서 보여 줍니다.
   예: "동생한테 소리부터 질렀더니 동생도 화를 냈어. ○○○ ○○○ ○○○ ○○ ○○ ○○다잖아."

### 6-4. 난이도 나누기 기준

표의 **단계 칸**을 그대로 쓰면 됩니다.

- **1단계**: 속담 1단계 20개 중 10개, 사자성어 1단계 15개 중 10개. 가장 흔하고, 뜻이 그림처럼
  떠오르는 것들입니다(원숭이도 나무에서 떨어진다, 작심삼일 등).
- **2단계**: 나머지. 뜻이 한 번 더 생각해야 나오는 것(벼는 익을수록 고개를 숙인다, 아전인수),
  한자가 어려운 것(형설지공, 청출어람)이 여기 있습니다.
- 추가로 나누고 싶으면 **오답 난이도**로 조절하는 게 문항을 새로 안 만들어도 돼서 편합니다.
  쉬운 판 = 오답을 태그가 확실히 다른 것으로(동물 얘기 vs 숫자 얘기). 어려운 판 = 6-3의
  3~4번 규칙(소재·태그 겹치기)을 강하게 적용.
- **한 세트 = 한 단계로 고정**하세요. 1단계 문제와 2단계 문제를 한 세트에 섞으면 라윤이
  "쉬웠다 어려웠다" 해서 페이스가 흔들립니다.
