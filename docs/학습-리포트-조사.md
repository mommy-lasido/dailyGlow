# 학습 리포트 — 다른 곳은 무엇을 보여주나

**조사한 날:** 2026-09-17

국내외 학습 서비스가 부모에게 어떤 리포트를 주는지 찾아 정리했다. 우리가
무엇을 넣고 무엇을 넣지 않을지 정하는 데 쓴다.

## 한눈에

| 서비스 | 부모에게 주는 것 |
|---|---|
| **IXL** (라윤이가 씀) | 리포트 여섯 종류 — 사용량, **막히는 자리**, 점수표, **문항 기록**, 성장 그래프, 진단+처방 |
| **Khan Academy** | 과목별 학습 시간, 익힌 기능 수, 숙달 정도, 활동 기록(시간·자료·종류로 정렬) |
| **아이스크림 홈런** | 시작·종료 **즉시 알림**, 주간 과목별 성취도와 성장 추이, 학습 성향·패턴 분석, 맞춤 처방 |
| **웅진 스마트올** | 단원별 분석, **오답 문항 분석**, 학습 습관 분석, 선생님의 오답 코칭 |
| **윙크** (시윤이가 쓰던 것) | 학습 수행 여부와 학습 시간, **틀린 문제**, 재학습이 필요한 부분, 이용 시간 관리 |
| **Duolingo** | 주간 메일 — 며칠 했는지, 점수, **지난주와 견주기**, 연속일 |
| **Prodigy** | 주별 푼 문제 수, 학년별 진도 비율, 월간 성적표 |

## 되풀이해서 나오는 다섯 가지

거의 모든 곳이 이 다섯을 공통으로 보여준다.

1. **얼마나 했나** — 날수, 시간, 판 수. 가장 먼저 나온다.
2. **무엇을 했나** — 과목·단원별로 나눠서.
3. **얼마나 잘했나** — 정답률 또는 그 서비스의 점수(IXL 의 SmartScore 같은 것).
4. **어디서 막히나** — IXL 의 Trouble Spots, 웅진의 오답 문항 분석, 윙크의
   "틀린 문제". **이 칸이 있는 곳과 없는 곳의 차이가 가장 크다.**
5. **그래서 무엇을 할까** — IXL 은 진단 결과로 할 것 목록을 만들어 주고,
   아이스크림과 웅진은 사람(선생님)이 코칭한다.

## 우리가 눈여겨볼 것

**IXL 의 Questions Log** — 아이가 푼 문제를 하나하나 볼 수 있다. 우리도 이제
1차에 틀린 것은 남기지만, **무엇을 답했는지**까지는 남기지 않는다.

**Duolingo 의 "지난주와 견주기"** — 이번 주 숫자만 보여주면 잘한 것인지 알 수
없다. 지난주와 나란히 놓으면 그 자리에서 판단이 선다. 우리 리포트에 아직 없다.

**아이스크림의 즉시 알림** — 아이가 학습을 시작하고 끝낼 때 부모에게 알린다.
우리는 넣지 않는다. 영숙님은 아이가 하는 것을 옆에서 보는 자리에 있고,
알림은 아이를 감시하는 쪽으로 기운다.

**사람이 하는 코칭** — 국내 서비스의 진짜 값어치는 대개 여기 있다(선생님 상담,
오답 코칭). 우리는 그 자리를 **영숙님과 클로드**가 맡는다. 그래서 우리 리포트는
"부모가 읽고 판단할 재료" 로 만들면 되고, 앱이 처방까지 흉내 낼 까닭이 없다.

## 우리가 하지 않기로 한 것

**점수·등급·또래 비교.** 여러 곳이 백분위나 학년 대비 수준을 보여주지만, 이
앱은 세 아이가 쓰는 집안 물건이다. 비교할 또래도 없고, 있어도 보여줄 까닭이 없다.

**아이에게 리포트 보여주기.** 리포트는 설정(부모 화면) 안에 둔다. 아이가 자기
정답률을 보면 점수로 스스로를 재게 된다.

**"집중력 점수" 같은 지어낸 수치.** 몇몇 서비스가 학습 습관·성향을 점수로
내놓지만, 우리 앱이 재는 것은 걸린 시간과 정답률뿐이다. 없는 것을 있는 것처럼
이름 붙이지 않는다.

## 지금 우리 리포트에 있는 것 / 없는 것

| | 우리 |
|---|---|
| 얼마나 했나 | **있음** — 날수·판수·분 |
| 무엇을 했나 | **있음** — 활동별 |
| 얼마나 잘했나 | **있음** — 첫 시도 정답률 |
| 어디서 막히나 | **있음(오늘부터 쌓임)** — 1차에 틀린 것 |
| 그래서 무엇을 할까 | **일부** — "눈에 띄는 것" 문장 |
| 지난주와 견주기 | **없음** ← 넣을 만하다 |
| 무엇이라고 답했나 | **없음** |
| 즉시 알림 | 넣지 않기로 함 |
