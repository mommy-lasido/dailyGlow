# 과학 차례

과학 내용의 순서는 **미국 과학 기준(NGSS)** 을 그대로 따른다. 라윤이가 국제학교에
다니며 미국 과정으로 수업을 듣기 때문이다 — 이 앱의 과학은 라윤이에게 학교와
어긋나는 길이 아니라 **학교와 같은 길**이다. 시윤이와 도윤이도 같은 차례로 간다.

한글을 『기적의 한글 학습』 단계표, 수학을 『기적의 계산법』 단계표 위에 얹은 것과
같다. 내가 순서를 지어내면 반드시 어긋나는 데가 생긴다.

출처: [nextgenscience.org 주제별 차례](https://www.nextgenscience.org/overview-topics)
(2026-09-16 확인)

## 학년별 주제

미국 초등학교는 킨더가든부터 5학년까지다. 학년마다 주제가 서넛이고, 모두 스물한
덩어리다.

| 학년 | 주제 |
|---|---|
| **킨더가든** | 밀기와 당기기(힘) · 동식물과 사는 곳 · 날씨와 기후 |
| **1학년** | 빛과 소리(파동) · 동식물의 생김새와 하는 일 · 해와 달과 별의 되풀이 |
| **2학년** | 물질의 생김새와 성질 · 생태계 속 서로 돕기 · 땅을 바꾸는 것들 |
| **3학년** | 힘과 움직임 · 사는 곳이 생물에 미치는 영향 · 한살이와 닮음 · 날씨와 기후 |
| **4학년** | 에너지 · 파동 · 몸의 생김새와 하는 일 · 땅을 바꾸는 것들 |
| **5학년** | 물질의 성질과 변화 · 생태계의 물질과 에너지 · 지구의 여러 겹 · 별과 태양계 |

각 학년에 **공학 설계**(무엇을 만들어 문제를 푸는 것)가 한 덩어리씩 더 붙어 있다.
이것은 만들 준비물이 필요하므로 이 앱에서는 다루지 않는다.

## 6학년은 어떻게 되나

NGSS 에서 6학년은 **중학교 묶음(6~8학년)** 에 들어간다. 초등학교 것이 아니다.
라윤이가 지금 3학년이므로 3년 뒤의 일이고, 그때는 물질의 짜임 · 힘과 운동 ·
생태계 · 지구의 역사 · 우주로 이어진다. 지금 정해 둘 일이 아니다.

## 우리 앱에서의 걸음 — 활동 이름은 **과학 놀이터**

아이는 **자기 학년 것부터** 시작한다(`startGrade`). 라윤이는 국제학교에서 미국
과정으로 배우므로 3학년부터, 시윤이와 도윤이는 킨더가든부터다.

**한 주에 배우는 것은 주제 하나가 아니라 그 안의 덩어리 하나다**(`weeklyScience`).
자석이면 붙는 물질 → 끌어당기는 까닭 → 두 극 → 자기장 → 나침반으로 다섯 주다.
주제를 한 주에 통째로 끝내면 한 학년이 서너 주 만에 지나가 버린다. 덩어리로
세면 스물한 주제가 **110주 치**, 곧 2년이 조금 넘는 분량이 된다.

지나온 학년 것은 **"지난 목록 보기" 단추 뒤 다른 화면**에 둔다. 이번 주 화면에
같이 깔아 두면 아이가 이것저것 눌러 집중이 흐트러진다. 백 개가 넘으므로
학년 → 주제 → 덩어리의 세 겹으로 접어 둔다.

덩어리의 제목은 **무엇을 배우는지 드러나게** 짓는다 — "왜 붙을까" 가 아니라
"철이 자석에 붙는 까닭" 처럼.

## 주제 하나를 만들 때

| 무엇 | 어떻게 |
|---|---|
| 개념 글 | 제목 달린 덩어리 서넛. **왜 그런지까지** 들어간다. 어린아이용이라도 개념은 깎지 않고 말만 쉽게 한다 |
| 한국어 영상 | 하나. 3분 안쪽이면 아이가 끝까지 본다 |
| 영어 영상 | 하나. 한국어 뒤에 온다 — 내용을 아는 채로 들어야 말이 장면에 붙는다 |
| 자막 | **두지 않는다.** 못 알아들어도 그냥 듣는다 |
| 집에서 하는 실험 | **두지 않는다.** 준비물은 결국 부모의 일이 되고, 집이 어지러워진다 |
| 맞히는 문제 | **두지 않는다.** 과학은 사지선다로 배워지지 않는다 |

영상을 고를 때는 **우리 화면 안에 넣을 수 있는 것인지 먼저 확인한다.** 만든 사람이
"유튜브에서만 보게" 막아 둔 영상이 있다.

## 영상 고르는 곳 (영숙님이 찾아 준 목록, 2026-09-16)

연령별 어린이 과학 채널 정리. 출처는 네이버 블로그 『키즈과학 유튜브 추천』
(starsukmom2/224333710171).

| 나이 | 채널 |
|---|---|
| 3~7세 | 핑크퐁 과학송·호기심송, 깨미 탐험대(EBS), 스토리봇 |
| 5세~초2 | EBS 키즈 『최고다! 호기심딱지』 — 생활과학 입문, 에그박사(곤충·동물) |
| 초1~초4 | 국립어린이과학관, 국립과천과학관, 국립중앙과학관, 서울시교육청 융합과학교육원 |
| 초등 고학년~ | 과학쿠키, 긱블, 과학드림, 수상한생선, 마크 로버 |

**다만 우리 자리에 그대로 쓰기는 어렵다.** 호기심딱지와 깨미 탐험대는 한 편이
11~14분짜리 애니메이션이고, 우리는 **이번 주의 개념 하나에 붙는 2~5분**이 필요하다.
좋은 채널이지만 성격이 다르다 — 부모가 따로 틀어 주는 자리에 더 맞는다.

제목만 보고 고르면 안 된다는 것을 여기서도 확인했다. 호기심딱지 『힘 대장!
탄수화물』 은 힘 이야기가 아니라 **탄수화물** 이야기다.
